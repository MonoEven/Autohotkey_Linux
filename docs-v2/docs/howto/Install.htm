How to Install AutoHotkey (Linux)

This page is for the AutoHotkey v2 Linux port (branch linux-port of MonoEven/Autohotkey_Linux). It provides an X11 backend (also used on XWayland) and a native Wayland backend. On Windows, install the official AutoHotkey from autohotkey.com instead.

Prebuilt packages (recommended)

Every GitHub release publishes two packages for 64-bit Linux:

  • autohotkey-linux-<version>-amd64.deb — Debian/Ubuntu package.
  • autohotkey-linux-<version>-amd64.tar.gz — generic tarball with the ahk launcher, the interpreter and the CLI/GUI installers inside.

Install the .deb package

sudo apt install ./autohotkey-linux-<version>-amd64.deb
ahk your-script.ahk

Install from the tarball

Extract the archive, then run the CLI or GUI installer from the unpacked tree:

tar xzf autohotkey-linux-<version>-amd64.tar.gz
cd autohotkey-linux
./tools/linux/install-gui.sh        # graphical wizard (zenity/yad)
./tools/linux/install.sh --prefix ~/.local
./tools/linux/install.sh            # system-wide (requires root)

The installer places the ahk launcher, the interpreter (ahk_core) and the bundled manual; ahk is also symlinked into ~/.local/bin (or /usr/local/bin).

Once installed, the ahk launcher also provides: ahk --version (shows the release, e.g. v2.0.26-linux.12), ahk --check (integrity / install method / latest release), ahk --uninstall (clean removal) and ahk --update [VER] (download + reinstall the latest, or a specific release for upgrading/downgrading, e.g. ahk --update 2.0.26-linux.8). Launcher commands use the -- prefix so plain names like update.ahk are always run as scripts. Only the latest release is kept on the Releases page; older releases with outdated launchers have been removed.

GNOME 49 Wayland zero-confirmation global hotkeys (optional)

On GNOME 49 Wayland, 1::-style global hotkeys can grab the physical key with no confirmation dialog (and even with no modifier) using the bundled GNOME Shell extension:

mkdir -p ~/.local/share/gnome-shell/extensions
cp -r /path/to/autohotkey-linux/extension/ahk-global-hotkeys@autohotkey.org \
      ~/.local/share/gnome-shell/extensions/
# ... then log out and back in (GNOME Shell loads extensions at startup),
# and enable it:
gnome-extensions enable ahk-global-hotkeys@autohotkey.org

The extension is a thin D-Bus broker; the interpreter picks the gnome-shell backend automatically on GNOME Wayland (AHK_INPUT_BACKEND=auto, default), or explicitly with AHK_INPUT_BACKEND=gnome-shell. Without the extension, or on other Wayland compositors, hotkeys fall back to the standard Global Shortcuts Portal backend (AHK_FORCE_GLOBAL_SHORTCUTS=1 forces Portal even behind XWayland).

Build from source

git clone --branch linux-port https://github.com/MonoEven/Autohotkey_Linux.git
cd Autohotkey_Linux
cmake -S . -B build-core
cmake --build build-core -j$(nproc)
build-core/source/linux/core/ahk_core your-script.ahk

Requirements: a C++17 compiler, CMake ≥ 3.16, X11/XTest development headers and GTK3 for the GUI; on Debian/Ubuntu: ninja-build libx11-dev libxtst-dev libxrandr-dev libxinerama-dev libxext-dev libxi-dev libwayland-dev wayland-protocols libxkbcommon-dev libffi-dev libdbus-1-dev libgtk-3-dev zlib1g-dev libjpeg-dev. The Wayland backend is optional (used when no X display is available).

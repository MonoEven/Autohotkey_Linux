AutoHotkey v2 Linux 移植版

本页维护 AutoHotkey v2.0.26 Linux 移植版的中文概览，随移植版同步更新。 完整的英文手册参见 文档首页 与 Linux 移植版总览（英文）。 源码与问题反馈： MonoEven/Autohotkey_Linux（分支 linux-port）。

这是什么

AutoHotkey v2 在 Linux 上的移植版：解释器与官方 v2.0.26 保持语法一致（仅支持 v2， 不支持 v1 语言）。官方文档集中除 Windows 专属部分外基本适用；本移植版的差异与平台说明见 英文总览。包含三个后端：X11（首选，含 XWayland）、 原生 Wayland（无 X 显示时）。

安装

从 Releases 下载最新的 autohotkey-linux-<版本>-amd64.deb 或 .tar.gz：

# Debian/Ubuntu：
sudo apt install ./autohotkey-linux-<版本>-amd64.deb
ahk your-script.ahk

# 通用 tar 包（解压后运行内置安装器）：
tar xzf autohotkey-linux-<版本>-amd64.tar.gz
cd autohotkey-linux
./tools/linux/install-gui.sh            # 图形向导（zenity/yad）
./tools/linux/install.sh --prefix ~/.local   # 或系统级安装（需 root）

# 或从源码构建：
git clone --branch linux-port https://github.com/MonoEven/Autohotkey_Linux.git
cd Autohotkey_Linux
cmake -S . -B build-core
cmake --build build-core -j$(nproc)
build-core/source/linux/core/ahk_core your-script.ahk

安装器会放置 ahk 启动器、解释器 ahk_core 与文档。 详细步骤见 Install（英文）。

能做什么（X11 / XWayland）

  • 热键 Hotkey() / #HotIf：键盘 + 鼠标（左/右/中/X1/X2 与滚轮）、 左右修饰键（<^a/>^a）、通配 *、Off/Suspend 解绑、 BadAccess 冲突报告、~/HotIf-false 透传。
  • 热字串 Hotstring()：键入触发真实现（C/*/O/X 选项、大小写跟随、HotIf）。
  • Send/SendText/Click/Mouse*/KeyWait/BlockInput、剪贴板、像素/显示器、对话框、ToolTip、 ImageSearch（BMP/ICO/PNG/GIF/CUR/JPEG/PPM 解码）等。
  • ComObject（D-Bus）、DllCall（.so + libffi）、GTK3 Gui。

原生 Wayland 模式支持窗口、虚拟键盘/指针、抓屏；窗口管理与全局热键需 XWayland。

与 Windows 的差异（要点）

  • 无 Win32 注册表/消息；RunAs 存储凭据但 Run 报文档化错误。
  • TrayTip/TraySetIcon、ComObjArray 等按文档报未移植错误。
  • 滚动/图形界面控件部分属性为 GTK 子集；详见英文总览。

Linux port note: this documentation accompanies the AutoHotkey v2 Linux port. Only AutoHotkey v2 syntax is supported — v1 syntax and the v1-to-v2 migration material are not part of this port. DllCall works with native .so libraries and COM is mapped onto D-Bus; Windows-only examples (GUI, Sound, window messages, …) are kept for reference. See linux-port.htm for the complete list of differences from Windows AutoHotkey.
